Hate speech detection you can actually audit.

A multilingual, context-aware classifier that returns a decision, a calibrated confidence, token-level evidence, and an explicit needs-review outcome when the model is unsure — instead of forcing every ambiguous post into a binary label.

Explainability

LIME and delete-one occlusion attributions, plus measured comprehensiveness and sufficiency — not decorative highlights.

Multilingual

English, Hindi (Devanagari and romanised) and Hinglish code-mixing, with per-language error reporting.

↻

Human review loop

Users report questionable predictions; reports are stored as review candidates and never auto-promoted to training labels.

How a post is handled

  1. Preprocess. URLs and mentions are normalized; script-mixing flags code-mixed text.
  2. Score. Text and context are fused into one canonical input and scored once.
  3. Decide. A cost-weighted threshold produced a three-way outcome: hate, non-hate, or human review.
  4. Explain. Influential tokens are highlighted, with faithfulness numbers attached.
  5. Escalate. Disputed or uncertain outputs feed a review queue, not the test set.

What this project does not claim

  • No vision or meme analysis: no image model is trained or evaluated.
  • No headline benchmark numbers: the shipped training set is a 30-record wiring dataset.
  • Attribution is not proof of intent, and generated rationales are kept separate from model evidence.
  • Not an enforcement system. It is built for assisted moderation with a human in the loop.
