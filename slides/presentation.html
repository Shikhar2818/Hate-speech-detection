Hate Speech Detection through Explainable AI and Reward-Optimized LLMs

Instructor: Dr. Pradeepika Verma · N2-WS-062 · pradeepika.verma@bennett.edu.in

An interpretable, multilingual, optionally multimodal moderation system that classifies posts and explains why.

Scroll or use PageDown · 12 slides

Motivation

Social platforms amplify identity-directed abuse at a speed humans cannot moderate alone.
Lexical classifiers miss sarcasm, code-mixing, memes, and thread context.
Black-box scores are hard to trust in public-safety and platform-governance settings.
We need accuracy, transparency, adaptability, and lower group-wise bias together.

Problem statement

Current detectors are mostly high-resource and text-only. They fail on low-resource languages, cultural variation, code-mixing, and multimodal hate.

xi = { Ti, Vi, Ci }

fθ(xi) → yi ∈ {0, 1}

T = text (multilingual / code-mixed), V = image or meme, C = conversational context, y = non-hate / hate.

Objectives

  • Classify hateful vs non-hateful social media content.
  • Support English, Hindi, and code-mixed posts; optional images.
  • Explain each decision with token evidence and a natural-language rationale.
  • Align explanations with human preferences using DPO.
  • Report fairness (FPR / macro-F1) by language group.

Proposed framework

Encode
XLM-R for T and C; optional CLIP for V.
Fuse
Gated weights over text, vision, and context.
Explain
LIME, attention, counterfactual cue hints.
Align
DPO on chosen vs rejected rationales.

Explainable AI

  • LIME — local linear surrogate over token perturbations.
  • Attention — CLS-to-token weights from the last encoder layer.
  • Faithfulness — drop in P(hate) after masking top evidence.
  • Counterfactuals — “removing cue X would likely reduce hate probability.”

Plausible stories are not enough; we measure whether highlighted tokens actually moved the model.

Reward-optimized LLM

A seq2seq policy (Flan-T5) generates HATE / NON_HATE plus a short justification.

Reward combines correctness, token overlap (faithfulness), length, and style.

LDPO = −log σ( β [ log πθ(e⁺|x)/πref(e⁺|x) − log πθ(e⁻|x)/πref(e⁻|x) ] )

Chosen rationales cite a target group and harmful intent. Rejected ones rely on rudeness or unrelated keywords.

Implementation

Python package hatexai
Synthetic multilingual JSONL for a CPU dry run
TF-IDF baseline + XLM-R classifier + DPO trainer
Streamlit demo for live explanations

Public data adapters: HateXplain, HASOC, Hateful Memes / MMHS150K.

Evaluation plan

  • Classification: accuracy, macro-F1, precision, recall, AUROC.
  • Explanation: comprehensiveness, mean reward, qualitative cases.
  • Fairness: false-positive rate by language and code-mix flag.
  • Ablations: text-only vs +context vs +vision vs +DPO.

Ethics

  • Not a sole automated punishment system — keep a human in the loop.
  • Identity language and dialect can inflate false positives.
  • Use licensed research datasets; do not scrape private accounts.
  • Explanations can look convincing while being unfaithful; we audit both.
